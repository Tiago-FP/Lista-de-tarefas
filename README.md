# ✨ Minha Lista de Tarefas (To-Do List)

Uma aplicação web simples, moderna e intuitiva para gerenciamento de tarefas diárias. Este projeto foi construído com foco didático, utilizando **HTML5, CSS3 e JavaScript puro (Vanilla JS)**, sem dependência de bibliotecas externas ou frameworks complexos.

---

## 🚀 Funcionalidades

- **Adicionar atividades:** Insira novas tarefas rapidamente digitando e pressionando `Enter` ou clicando no botão **+ Adicionar**.
- **Diferenciação visual clara (Pendente vs. Concluída):**
  - **⏳ Pendente:** Destaque lateral em âmbar e etiqueta indicativa amarela.
  - **✓ Concluída:** Fundo verde-esmeralda suave, texto riscado e etiqueta verde.
- **Barra de Progresso em Tempo Real:** Acompanhe visualmente a porcentagem e a quantidade de tarefas concluídas no dia.
- **Remover atividades:** Exclua tarefas individualmente a qualquer momento.
- **Salvamento Automático (`localStorage`):** Suas tarefas ficam salvas diretamente no navegador e permanecem lá mesmo após fechar a aba ou reiniciar o computador.

---

## 📂 Estrutura do Projeto

O código foi organizado separando claramente cada responsabilidade para facilitar o estudo:

```text
lista-de-tarefas/
├── index.html   # Estrutura da página (esqueleto, formulário e lista)
├── style.css    # Estilo visual (cores, degradês, animações e estados)
├── script.js    # Lógica da aplicação (manipulação do DOM e salvamento)
└── README.md    # Documentação do projeto
```

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica (`main`, `header`, `section`, `form`, `ul`).
- **CSS3:** Flexbox, gradientes modernos, transições suaves e design responsivo.
- **JavaScript (ES6+):** Manipulação do DOM, eventos (`addEventListener`) e persistência de dados com `localStorage`.

---

## 💻 Como Executar o Projeto

Como o projeto utiliza tecnologias nativas da web, você não precisa instalar nada:

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/lista-de-tarefas.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo **`index.html`** para abri-lo em qualquer navegador web.
